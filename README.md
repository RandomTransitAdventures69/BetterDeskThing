# MyDeskThing

Oh hey there!

DeskThing was maxing out my CPU, so I made a **VERY lightweight version**.

MyDeskThing is a simple, fast dashboard for Spotify, weather, and transit that runs locally with a Python backend and a plain HTML/CSS/JavaScript frontend.

## Requirements

* A computer
* Python
* A Spotify App
* An MBTA API key
* Internet access

That's pretty much it.

## Why?

Because apparently a dashboard displaying some text and album artwork does **not** need to turn your CPU into a space heater.

MyDeskThing is intentionally simple:

* Plain HTML
* Plain CSS
* Plain JavaScript
* Python + FastAPI
* WebSockets for Spotify updates
* No giant frontend framework
* No unnecessary background processes

The goal is simple:

**Make it fast. Make it lightweight. Make it work.**
